# Known UI gaps: baseline of 2026-10-01

Found by a read-only survey. **Check each item is still true before acting
on it,** and delete lines as they are fixed, so this file stays a to-do list
rather than a history. Line numbers drift; search for the pattern.

## P1: accessibility and correctness

- **`chili` as small text** fails AA (3.68–4.24:1 on card, surface and bg)
  and is used about 270 times. Keep `chili` for fills, icons and large text.
  Add a lighter text variant (around 4.6:1 on `card`), check it with
  `contrast.mjs`, and move small-text uses onto it.
- **`<html lang="en">` is fixed** (`app/layout.tsx:83`), although Thai is the
  default. Screen readers read Thai with English rules. Have LangProvider set
  `document.documentElement.lang` whenever the language changes.
- **Reduced-motion gaps:**
  - `animate-pulse` (ContestView.tsx:287, ContestDesk.tsx:44,
    GalleryPage.tsx:205, party/PartyClock.tsx:87) and `animate-spin`
    (GalleryPage.tsx:254) keep running; add `motion-reduce:animate-none`.
  - ProfilePictures.tsx:256-269 animates height with no check.
  - PopotoRare still waits up to 900ms (`fx.charge`) when nothing animates.
- **Untranslated labels:** `aria-label="Close"` ×6 (Modal.tsx:169/405,
  Toast.tsx:247/376, …). There is hard-coded English at MemberBoard.tsx:730
  and 1100, and CompareClient.tsx:98.
- **Small targets:** TellButton.tsx:82 (`p-0.5`) and the ✕ close buttons
  (`px-2 py-1`) are below 24px.

## P2: friction

- There is no `app/not-found.tsx`, `error.tsx`, `global-error.tsx` or any
  `loading.tsx`. `notFound()` is called in seven places and lands on Next's
  default 404.
- **No `viewportFit: "cover"`,** so `env(safe-area-inset-bottom)` on the tab
  bar (Nav.tsx:348, 420) likely resolves to 0 on iPhones.
- **Sheets size with `vh`,** not `dvh`.
- **No `color-scheme: dark`,** so native controls and scrollbars render
  light-themed.
- **`window.prompt` as the clipboard fallback** (TellButton.tsx:60,
  PfHelper.tsx:134, ShareParty.tsx:61). Use `navigator.share()` or a
  popover instead.
- **Skeletons are inconsistent:** Skeleton is used only in MemberBoard;
  ContestView and ContestDesk use `animate-pulse` boxes.
