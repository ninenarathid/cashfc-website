Use the attached picture only as the reference for the pixel art style, the colours and the thick dark outline of a cozy 2D town game. Draw a new sprite sheet of small user interface icons for that game, in the same pixel art style.

Each icon is drawn on its own 16 by 16 pixel grid, scaled up big so every pixel of the icon is a large crisp square, all icons the same size, simple and bold so they read clearly when shown small, with a thick dark outline and two or three tones per colour. Eight icons in one row across the canvas, evenly spaced with wide empty gaps between them, not touching, not overlapping:
These are mouse cursors for the game, so each must read clearly on grass, stone and dark ground: a thick dark outline all round and light colours inside. 1) a fantasy pointer arrow pointing up and to the left exactly like a normal mouse cursor, its tip at the top-left corner, cream white with a gold trim, with a tiny four-pointed sparkle star beside its tail, the sparkle small; 2) the same arrow, the sparkle bigger and bright; 3) the same arrow, the sparkle biggest with little rays; 4) the same arrow, the sparkle faded small again; 5) a small cute hand in a cream glove pointing straight up with its index finger, the fingertip at the very top; 6) the same pointing hand pressing down a little, the finger slightly bent; 7) the same pointing hand back up, with a tiny motion line by the fingertip; 8) the same gloved hand closed in a grabbing fist.

Crisp pixel art with hard square pixel edges, no anti-aliasing, no blur, no gradients, no glow. Transparent background, no frames or boxes around the icons, no shadows, no text, no letters, no numbers.
